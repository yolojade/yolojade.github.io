초등 영어 동사 양면 플래시카드

data.txt를 같은 폴더에 넣으면 영어 단어가 자동 적용됩니다.

인쇄 방법: 양면 인쇄하기 → 프린터 설정에서 배경 그래픽 체크 → 양면 인쇄 / 긴 쪽으로 넘기기를 선택하세요.
1쪽은 영어 앞면, 2쪽은 뜻 뒷면으로 출력됩니다. 프린터마다 여백이 다르므로 처음에는 1세트만 테스트 출력하세요.

기본 단어 20개를 불러왔습니다.

플래시 카드 학습

data.txt 작성 방법 보기

HTML 파일과 같은 폴더에 data.txt 파일을 만들고 아래 형식으로 입력하세요. 

go|가다|I go to school.|고|/goʊ/
come|오다|Come here.
eat|먹다|I eat lunch.

한 줄에 한 단어씩 입력합니다. 형식은 영어|뜻|예문 입니다. 발음을 직접 쓰고 싶으면 영어|뜻|예문|한글 발음|발음기호 형식도 사용할 수 있습니다.

크롬에서 파일을 더블클릭으로 열면 보안 설정 때문에 data.txt 자동 읽기가 막힐 수 있습니다. 그럴 때는 data.txt 직접 불러오기 버튼을 사용하거나 VS Code Live Server로 실행하세요.
