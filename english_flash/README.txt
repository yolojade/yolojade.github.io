사용 방법

1. 압축을 풉니다.
2. index.html과 data.txt가 같은 폴더에 있는지 확인합니다.
3. 가장 쉬운 방법:
   - index.html을 크롬으로 열고, data.txt 직접 불러오기 버튼을 눌러 data.txt를 선택합니다.
4. 자동 연결 방법:
   - VS Code에서 폴더 열기
   - Live Server 확장 실행
   - 브라우저에서 열면 data.txt가 자동으로 적용됩니다.
5. 인쇄:
   - 양면 인쇄하기 클릭
   - 인쇄 설정에서 '배경 그래픽' 체크
   - '양면 인쇄 / 긴 쪽으로 넘기기' 선택

주의:
크롬에서 index.html을 더블클릭으로 열면 보안 설정 때문에 data.txt 자동 읽기가 막힐 수 있습니다.
이 경우 data.txt 직접 불러오기 버튼을 사용하면 됩니다.
