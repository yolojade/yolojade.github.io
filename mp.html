프롬프트 일괄 생성기 사용법

공통 프롬프트는 그대로 두고, [아이템] 부분만 여러 단어로 바꾸고 싶을 때 사용하는 도구입니다.

1. 공통 프롬프트 입력

계속 반복해서 사용할 프롬프트를 왼쪽 입력창에 작성합니다.

내용이 바뀌어야 하는 위치에는 반드시 [아이템]이라고 입력합니다.

귀여운 손그림 스타일의 교육용 아이콘, [아이템] 1개만 단독으로 그려줘.

2. 아이템 목록 입력

오른쪽 입력창에 변경할 단어를 한 줄에 하나씩 입력합니다.

종이 플라스틱 유리병

3. 프롬프트 생성

프롬프트 생성 버튼을 누르면 아이템 개수만큼 결과가 만들어집니다.

[종이] 1개만 단독으로 그려줘. [플라스틱] 1개만 단독으로 그려줘. [유리병] 1개만 단독으로 그려줘.

4. 결과 복사

복사 버튼을 누르면 해당 프롬프트 하나만 복사됩니다.

전체 복사 버튼을 누르면 만들어진 모든 프롬프트가 한 번에 복사됩니다.

5. 결과 지우기

결과 지우기 버튼은 생성 결과만 삭제합니다.

공통 프롬프트와 아이템 목록은 그대로 남아 있으므로 다시 수정해서 사용할 수 있습니다.

알아두면 좋은 점

공통 프롬프트 안에 [아이템]이 여러 번 있어도 모두 같은 단어로 변경됩니다.

입력: [아이템] 아이콘을 그리고, [아이템]의 특징이 잘 보이게 해줘. 결과: [종이] 아이콘을 그리고, [종이]의 특징이 잘 보이게 해줘.

빈 줄은 자동으로 제외되므로 아이템 사이에 빈 줄이 있어도 괜찮습니다.
